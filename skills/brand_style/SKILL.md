# 品牌语气规范

遵守可信、尊重受众的品牌语气；具体表达服从渠道与当前任务，不统一要求克制。不要攻击竞品，不制造焦虑，不使用过度饥饿营销。优先使用清晰、具体、可验证的表达。

渠道语气服从具体任务：小红书种草可使用轻松口语、短句、适量表情和场景共鸣，不必写成正式公告。可信指事实有依据，不要求语气生硬；不得编造亲测经历或借情绪表达暗示产品功效。

事实准确与表达活泼分别判断。种草可使用有吸引力的标题、情绪表达、生活共鸣、短句和自然口语；不把这些表达一概视为夸张或不专业。联名兴趣、角色偏好和场景吸引力本身可以构成推荐理由。资料仅支持系列共同特点时，允许围绕整个活动种草，产品名可简洁列出，不强制每款都有独立卖点或适合人群。不得为增强感染力虚构体验、口味、功效、价格或稀缺性。
